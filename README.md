DevPilot 是一套面向学生开发团队与小型技术团队的 GitHub 项目协作与 AI 工程助手。

它以团队真实 GitHub 仓库为数据来源，通过 Webhook 和 GitHub API 同步 Push、Issue、Pull Request、Review 等研发活动，并在本地建立工作空间、项目、成员、任务、通知、审计和知识库模型。

DevPilot 不准备复刻 GitHub，而是解决 GitHub 原生协作之外的“项目上下文”问题：

- 项目活动分散，成员不知道最近发生了什么；
- 会议纪要、需求和代码提交缺乏关联；
- Issue、PR 与团队任务无法统一追踪；
- 新成员理解项目和历史决策成本高；
- 周报、进度和风险依赖人工整理；
- AI 助手无法安全调用真实项目数据和业务工具。

它的核心业务链路是：

```
创建工作空间
→ 邀请成员
→ 创建项目
→ 绑定 GitHub 仓库
→ 接收 GitHub Webhook
→ 验签与幂等落库
→ 异步解析事件
→ 生成项目活动时间线
→ 关联任务、Issue、PR 与成员
→ 发送通知
→ Agent 基于真实上下文提供协助
```

GitHub 官方要求 Webhook 接收方使用密钥验证 X-Hub-Signature-256，签名算法为 HMAC-SHA256，并建议使用恒定时间比较避免时序攻击。这正好构成项目中一条真实的安全工程链路。
